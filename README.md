# ARENA ISTANBUL
**Arena Istanbul** is a turn-based fighting game set in a historical, story-driven atmosphere inspired by 1400s Istanbul.  
Players create their own character, progress through story-based duels, earn gold, buy equipment, and improve their abilities while going through parts of the story-line through cutscenes.

This project was developed as a learning-focused game project for the CS-102 class.

## TECH STACK
- **Language:** Java (100%)
- **Application Type:** Desktop application
- **Graphics:** Java Swing
- **Game Type:** Turn-based, story-driven fighting game
- **Platform:** Windows / macOS / Linux (with JDK installed)

## HOW TO RUN THE GAME
### DOWNLOADING THE PROJECT
You can download this project in 2 ways :

**1) Download ZIP (Easiest)**
1. Click the green **<> Code** button on the GitHub page  
2. Click **Download ZIP**  
3. Extract the ZIP file to any folder on your computer

**2) Clone with Git**
If you have Git installed, open a terminal and run:
bash
git clone https://github.com/konudemir/Arena-Istanbul.git

### RUNNING THE GAME
> Make sure you have the **Java Development Kit (JDK)** installed before running the game.
> If you don't have JDK you can install it easily via online tutorials.

1. Open the project in an IDE (VS Code, IntelliJ IDEA, etc.). If you do not have one installed, you may check Youtube on how to install any IDE.
2. Open the project folder you have downloaded in the previous instructions on your IDE. 
3. Locate **`Main.java`** file inside the **`M`** folder inside the project.
4. Run `Main.java` by clicking the run button on your IDE or writing **javac Main.java** and **java Main** and pressing enter after each time on your IDE's command line while being inside the project folder.

The game will start by a window popping in at most a few seconds. Wait for 2-3 seconds before clicking anything in the window for safety.

### THE FIGHT MECHANICS
The fight mechanics for this game is turn-based. This means that you can only move your character after your opponent has moved its character, and vice versa. When your turn comes you may choose from 5 buttons to choose your next act at the battle:
1. Move right
2. Move left
3. Attack - attacks the opponent with a power that is coming from your equipment and a bit of randomness
4. Rest - boosts your stamina
5. Use pet - your pet attacks the opponent (if you have one) while you do not use any extra stamina
The battle ends once a side ends of stamina or health. You are rewarded with gold if you win. And gold is removed from your account if you lose.
